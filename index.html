RockSolid

SolidJS component library

Build modern interfaces with RockSolid.

RockSolid is a component library built with SolidJS and Tailwind CSS for building modern, consistent, and accessible user interfaces.

Get started Explore components

Why RockSolid?

Everything you need to build consistent interfaces.

Reusable components, a consistent API, and a flexible theme system help you build applications faster without recreating common UI patterns.

SolidJS

Built specifically for SolidJS applications with APIs designed for the SolidJS ecosystem.

Tailwind CSS

Use familiar Tailwind CSS utilities for flexible and predictable styling.

Accessible

Components consider keyboard interaction, focus management, semantic HTML, and ARIA support.

TypeScript

Get type safety and autocomplete across component APIs and theme configuration.

Themeable

Customize colors, typography, rounded corners, shadows, and other design tokens.

Composable

Combine components to create more complex interfaces while keeping your code reusable and maintainable.
