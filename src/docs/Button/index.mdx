# Button

The Button component is used to trigger an action or event. It supports
multiple colors, visual variants, sizes, icons, disabled states, and
full-width layouts.

## Accessibility

* Use descriptive text that clearly communicates the Button's action.
* Do not rely on color alone to communicate meaning or state.
* Use the `disabled` prop when an action is unavailable.
* When using `startIcon` or `endIcon` for decorative icons, set
  `aria-hidden="true"` on the icon so it is hidden from assistive
  technologies.
