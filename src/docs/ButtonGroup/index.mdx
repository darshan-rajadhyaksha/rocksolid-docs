# ButtonGroup

The ButtonGroup component groups related buttons together into a single,
connected control. It can be used to present actions that belong to the
same context or provide a set of closely related choices.

## Accessibility

-  Give the button group an accessible name using `aria-label` or `aria-labelledby` to describe its purpose.
- Group related actions together so their relationship is clear to users.
- Ensure each button has an accessible name that describes its action.
- Do not rely on color alone to communicate the meaning of an action.
- Keep the order of buttons consistent with the expected action flow.
