| Prop      | Type                                                       | Required | Default   | Description |
| --------- | ---------------------------------------------------------- | -------- | --------- | ----------- |
| as        | `string`                                                   | No       | `"div"`   | The HTML element used to render the button group. |
| children  | `JSXElement`                                               | No       | —         | The buttons or other content rendered inside the group. |
| class     | `string`                                                   | No       | —         | Custom CSS classes applied to the button group. |
| color     | `"default" \| "success" \| "warning" \| "info" \| "error"` | No       | `"default"` | The color scheme applied to the button group. |
| disabled  | `boolean`                                                  | No       | `false`   | Disables the button group and prevents interaction with its buttons. |
| fullWidth | `boolean`                                                  | No       | `false`   | Makes the button group span the full width of its container. |
| orientation | `"horizontal" \| "vertical"` | No | `"horizontal"` | Controls the orientation of the buttons in the group. |
| size      | `"small" \| "medium" \| "large"`                           | No       | `"medium"` | Controls the size of the buttons in the group. |
| variant   | `"solid" \| "filled" \| "outlined" \| "ghost"`             | No       | `"solid"` | Controls the visual style of the button group. |
