# Divider

The Divider component provides a visual separation between sections of
content. It helps organize related content and makes the structure of
an interface easier to understand.

## Accessibility

- Use the Divider to visually and semantically separate sections of content.
- For purely decorative dividers that do not convey meaningful structure,
  use `aria-hidden="true"` so they are ignored by assistive technologies.
- Do not rely on the Divider alone to communicate important information.
