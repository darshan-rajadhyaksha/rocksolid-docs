| Prop      | Type                                                                                                                            | Required | Default   | Description                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------------------------- | -------- | --------- | --------------------------------------------------------------- |
| children  | `JSXElement`                                                                                                                    | No       | —         | Content displayed inside the Link.                              |
| class     | `string`                                                                                                                        | No       | —         | Custom CSS class to apply to the Link.                          |
| color     | `"inherit" \| "default" \| "success" \| "warning" \| "info" \| "error" \| "textPrimary" \| "textSecondary" \| "textTertiary" \| "disabled"` | No       | `"default"` | Controls the semantic color of the Link.                        |
| href      | `string`                                                                                                                        | No       | —         | Specifies the URL or path that the Link navigates to.           |
| truncate  | `boolean`                                                                                                                       | No       | `false`   | Truncates the Link content when it exceeds the available space. |
| underline | `"always" \| "hover" \| "none"`                                                                                                 | No       | `"hover"` | Controls when the Link displays an underline.                   |
