| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| align | `"inherit" \| "left" \| "center" \| "right" \| "justify"` | No | `"inherit"` | Controls the horizontal alignment of the text. |
| as | `string` | No | Based on `variant` | Controls the semantic HTML element rendered by the component. |
| class | `string` | No | — | Adds custom CSS classes to the Typography component. |
| color | `"inherit" \| "default" \| "success" \| "warning" \| "info" \| "error" \| "textPrimary" \| "textSecondary" \| "textTertiary" \| "disabled"` | No | `"inherit"` | Controls the color of the text. |
| variant | `"inherit" \| "h1" \| "h2" \| "h3" \| "h4" \| "h5" \| "h6" \| "body1" \| "body2" \| "code"` | No | `"body2"` | Controls the visual typography style of the text. |
| truncate | `boolean` | No | `false` | Truncates overflowing text when enabled. |
