| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| as | `"th" \| "td"` | No | Automatic | Controls the HTML element used for the cell. Defaults to `th` inside `TableHead` and `td` otherwise. |
| class | `string` | No | — | Adds custom CSS classes to the table cell. |
| align | `"left" \| "center" \| "right" \| "justify"` | No | `"left"` | Controls the horizontal alignment of the cell content. |
