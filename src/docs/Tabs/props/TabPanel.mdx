| Prop  | Type     | Required | Default | Description                                                                  |
| ----- | -------- | -------- | ------- | ---------------------------------------------------------------------------- |
| class | `string` | No       | —       | Adds custom CSS classes to the tab panel.                                    |
| value | `string` | **Yes**  | —       | Identifies the panel and associates it with a `Tab` that has the same value. |
| children | `JSXElement` | No | — | The content to display inside the tab panel. |
