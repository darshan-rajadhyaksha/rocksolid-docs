| Prop        | Type                         | Required | Default        | Description                                             |
| ----------- | ---------------------------- | -------- | -------------- | ------------------------------------------------------- |
| centered    | `boolean`                    | No       | `false`        | Centers the tabs within the available space.            |
| class       | `string`                     | No       | —              | Adds custom CSS classes to the tabs container.          |
| orientation | `"horizontal" \| "vertical"` | No       | `"horizontal"` | Controls the direction in which the tabs are displayed. |
