# IconButton

The IconButton component provides a compact button for actions that can
be represented by an icon. It is useful for common actions such as
closing, editing, deleting, or opening additional options.

## Accessibility

* Provide an accessible label for every IconButton.
* Use a concise action-oriented label such as `Close`, `Edit`, or `Delete`.
* Do not rely on the icon alone to communicate the button's purpose.
* Use `disabled` when the action is temporarily unavailable.
* Ensure the button has sufficient contrast and a visible focus state.

## API

### IconButton

The IconButton component accepts an icon as its content and supports
