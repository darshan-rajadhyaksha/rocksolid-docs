| Prop     | Type                             | Required | Default    | Description                                            |
| -------- | -------------------------------- | -------- | ---------- | ------------------------------------------------------ |
| children | `JSXElement`                     | Yes      | —          | The icon or SVG displayed inside the button.           |
| class    | `string`                         | No       | —          | Additional CSS classes applied to the IconButton.      |
| color    | `"default" \| "success" \| "warning" \| "info" \| "error"` | No | `"default"` | Controls the semantic color of the IconButton. |
| disabled | `boolean`                        | No       | `false`    | Disables the IconButton and prevents user interaction. |
| size     | `"small" \| "medium" \| "large"` | No       | `"medium"` | Controls the size of the IconButton.                   |
